# Market Screener

Кросс-активный скринер рынка: режим → финансовые условия → классы активов → отдельные инструменты.
Данные обновляются раз в день через GitHub Actions, страница публикуется на GitHub Pages.

## Установка (один раз, ~10 минут)

### 1. Репозиторий
1. github.com → **New repository** → имя, например `market-screener`.
2. Видимость **Public**. GitHub Pages на бесплатном плане работает только с публичными репозиториями. Секретов в коде нет, ключ лежит отдельно.
3. Создай репозиторий пустым, без README.

### 2. Загрузить файлы
Самый простой способ — через браузер:
1. В репозитории: **Add file → Upload files**.
2. Перетащи папки `collector`, `docs` и файлы `requirements.txt`, `README.md`, `.gitignore` → **Commit changes**.
3. Папку `.github` браузер часто не загружает (она скрытая), поэтому workflow создаём вручную:
   **Add file → Create new file**, имя файла `.github/workflows/update.yml`.
   Вставь содержимое файла `.github/workflows/update.yml` из архива → **Commit changes**.

Если пользуешься git:
```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/<user>/market-screener.git
git push -u origin main
```

### 3. Ключ FRED
**Settings → Secrets and variables → Actions → New repository secret**
- Name: `FRED_API_KEY`
- Secret: твой ключ

Необязательно: `COINGECKO_API_KEY` — бесплатный demo-ключ CoinGecko. Без него скрипт ждёт между запросами, с ним работает быстрее и стабильнее.

### 4. GitHub Pages
**Settings → Pages → Build and deployment → Source: GitHub Actions**.

### 5. Первый запуск
**Actions** → если попросит, нажми «I understand… enable workflows» → **Update screener** → **Run workflow**.
Через 3–5 минут страница появится по адресу `https://<user>.github.io/market-screener/`.

Дальше всё работает само: каждый день в 22:30 UTC (23:30 по Валенсии зимой).

## Если что-то сломалось
- **Actions → последний запуск красный.** Открой лог шага *Collect data*. Чаще всего это временная блокировка со стороны Yahoo: на следующий день проходит само. Если Yahoo не отдал вообще ничего, скрипт останавливается и не затирает вчерашнюю страницу.
- **На странице жёлтая плашка «N data warnings».** Отдельные тикеры или источники не ответили. Нажми на неё, там список. Остальная страница строится как обычно.
- **«FRED_API_KEY is not set».** Секрет не добавлен или в имени опечатка.

## Как это устроено
```
collector/universe.py   список инструментов по классам (редактируется здесь)
collector/sources.py    загрузка: Yahoo, FRED, DefiLlama, CoinGecko
collector/metrics.py    расчёты: RS, тренд, объём, накопление, ширина, RRG
collector/build.py      сборка всего → docs/data.json
docs/index.html         страница (читает data.json)
state/state.json        история состава крипто-топ-10 (создаётся сама)
```

### Метрики
| Колонка | Что считает |
|---|---|
| RS 1W / 1M / 3M | Доходность относительно родителя за 5 / 21 / 63 торговых дня, нормированная на собственную историю инструмента. Родитель: для классов — ACWI, для членов — прокси класса, для акций — секторный ETF. |
| Trend | −3…+3: цена выше или ниже MA50 и MA200, MA50 выше или ниже MA200. |
| Volume | Долларовый объём за 20 дней относительно 120 дней. |
| Accum. | Объём в дни роста минус объём в дни падения за 20 дней, от −1 до +1. |
| > MA50 | Для групп — доля членов выше MA50 (ширина). Для инструментов — доля последних 20 дней выше MA50. |

**Макро-режим.** Рост — 3-месячная динамика медь/золото, XLY/XLP, HYG/IEF. Инфляция — 10Y breakeven, DBC/IEF, TIP/IEF.

**Ликвидность.** Нетто-ликвидность ФРС (баланс − TGA − RRP), доллар, спреды HY, стейблкоины.

**Крипто-топ-10.** Живой список по капитализации без стейблкоинов и обёрнутых токенов. Монета входит в список, когда поднимается в топ-10, а выходит, только когда опускается ниже 12-го места. Это защищает от ежедневного дёрганья состава.

### Ограничения
- «Приток» в TradFi — это прокси по объёму и накоплению, а не реальные потоки в фонды.
- У валют, фьючерсов и индексов нет объёма, поэтому там стоит n/a.
- Ширина рынка США считается по ~56 крупнейшим бумагам, а не по всем 500.
- История состава крипто-топ-10 копится с первого запуска. До этого для расчётов используется текущий состав.

### Локальный запуск
```bash
pip install -r requirements.txt
FRED_API_KEY=... python collector/build.py
cd docs && python -m http.server   # открыть http://localhost:8000
```
Тест без интернета на синтетических данных: `MOCK=1 python collector/build.py`.
